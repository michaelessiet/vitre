# Visual references

Native captures use a temporary Vitre home with synthetic workspace content.
Recorded on **2026-10-31** on macOS, at a 16 px UI font size, 80% glass opacity,
and 2× display scale.
These are full-window screenshots; open an image at full size to inspect controls.

values from the theme file. Row names and device counts are fixture/environment
data, not fixed interface requirements. The earlier centered outlined-button
device list is superseded by the command-row picker shown here.
